# Prior Exposure Declarations

**Declarations are NOT stored in this repository.**

They are held privately by the project lead, and with counsel where any declaration is
non-empty. This repository records only that the process was followed.

## Why not here

This repository is public and its history is permanent. A declaration is a document in
which a contributor states, in writing, what other projects' terms they have accepted.
That is exactly the document an adversarial reader would want, phrased in exactly the
vocabulary they would want, and it cannot be meaningfully retracted once pushed.

Keeping declarations private costs nothing and forecloses that.

## Process

1. Project lead holds the declaration template (not in this repo).
2. Each contributor completes one before their first substantive commit.
3. Any non-empty answer is routed to counsel before that contributor takes on
   implementation work. This is a precaution, not a finding.
4. The lead records completion in the register below.

## Note on what is and is not at issue

Copyright does not restrict what is in a contributor's memory, and the design
rationale of prior models in this lineage is published in the peer-reviewed
literature (see `docs/canon.md`). The question the declaration addresses is
**contractual**: obligations accepted by signature or click-through remain in force
regardless of how this project sources its material.
