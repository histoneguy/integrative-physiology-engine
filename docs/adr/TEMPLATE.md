## What this lumping disqualifies as evidence

Optional where the record lumps nothing. Required where it collapses a distinction.

Not what the model cannot OUTPUT - what it can no longer be CALIBRATED AGAINST. Name the
experimental paradigms whose perturbed variable no longer matches a model variable, and
name the class that still does.

A simplification does not only defer detail; it excludes an evidence base. ADR 0010 was
sourced against head-out immersion for three sessions before the mismatch surfaced, and
nothing in the repo recorded that the exclusion existed. See ADR 0011.
